Yogglez

A central, modular goggle framework for Minecraft modpacks — data-driven JSON and KubeJS extensibility.

Work in progress

Instead of carrying a separate handheld analyzer for every mod, you equip a unified pair of goggles and upgrade them with lenses. The headgear handles UI and information display exclusively, operating as a standalone framework that can optionally integrate with Create’s Engineer’s Goggles.

  • Universal modular headgear with a modular lens system
  • Pure analysis — goggles display information, tools stay in your hand
  • Modular physical sockets for server-side lens items
  • Data-driven extensibility via JSON and KubeJS
